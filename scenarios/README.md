# Scenarios

Scenario folders explore situations the way location folders explore geography. Each folder begins with an index and breaks a large interaction into linked states, approaches, complications, investigations, and outcomes. Follow the links that match what the players actually do; do not run every file in order.

## Available scenario sets

- [Kobold Negotiations](kobold_negotiations/index.md) — approaches to Yiznak, terms for food and engineering work, order-dependent changes, optional bugbear sabotage, and ways to preserve the agreement without solving the conspiracy.

## How to use these files

- Start at the scenario's `index.md` and open the approach chosen by the players.
- Treat “Continue” links as likely transitions, not mandatory rails.
- Move to an outcome as soon as the players have actually earned it.
- Complications are optional. A clean success is allowed to remain clean when the session does not need another turn.
- Scenario files interpret campaign material; room geography and combat statistics remain in [Locations](../locations/index.md).
