# Locations

Location references are written for live use. Each area page summarizes what is visible, what the players can accomplish there, what is concealed, and where each exit leads.

- [The Keep](keep/index.md) - the campaign's fortified home base, roadside rest stop, market, chapel, and frontier command.
- [The Caves of Chaos](caves/index.md) - a room-by-room, text-adventure reference for the ravine and all 64 numbered cave areas.
- [The Northern Woods](northern_woods/index.md) - an 18-area exploration network north of the road, with the manufactured-famine clue trail, night undead patrols, and the hidden Mad Hermit.
- [The Southern Forest and Northern Fens](southern_forest/index.md) - an 18-area exploration network containing Maren's lizardfolk encounter, the first marsh trade, the black widow lair, Aldric's bandit camp, and the Baron's concealed transfer route.
