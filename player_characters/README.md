# Player Characters

This directory holds player character records and table-facing sheets for accompanying characters in the Riverfork Keep campaign.

- [Blank character sheet](character-sheet-template.md) — copy this file and rename the copy for a new character.
- [Father Demetrios Kallistos](father-demetrios-kallistos.md) — allied cleric and diplomatic support. This sheet contains a clearly marked Dungeon Master note.

Ordinary player character histories should remain player-safe. Any accompanying-character sheet containing private information must mark its Dungeon Master section clearly.
